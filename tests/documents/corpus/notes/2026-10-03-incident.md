# Incident: pump 2 stopped, 3 October

Pump 2 stopped in the afternoon with the red light flashing five times (code 5, pressure switch fault).
The bench log shows a long run of sensor errors just before it stopped.

What we did:
1. Isolated pump 2.
2. Cleared the code by holding the button for five seconds.
3. Pump restarted and ran normally.
