# mixed/docs

Hand-written documents about the Rust workspace in `mixed/` (crates `inventory` and `shop`). They
name its functions, types and files, and were checked against the code.

- `setup-guide.md`: building and testing the workspace, and where things live.
- `refund-policy.md`: the shop's refund rules and the manual refund process.
- `design-note.md`: why stock and checkout are split, and the checkout rule.
