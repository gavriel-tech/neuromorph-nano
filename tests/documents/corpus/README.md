# corpus

The material the engine studies. Question files name paths relative to this folder.

- `manual/`: a service and maintenance manual for a made-up water pump (Markdown, hard-wrapped).
- `textbook/`: two short textbook chapters, one Markdown (soft-wrapped), one plain text.
- `notes/`: 32 dated work notes from a made-up pump trial; later notes can overturn earlier ones.
- `data/`: a parts inventory (CSV), suppliers (TSV), orders (JSON lines) and a service log.
- `mixed/`: a two-crate Rust workspace with documents that describe it (`mixed/docs/`).

Everything here is invented for testing.
