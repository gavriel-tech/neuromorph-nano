# textbook

Two short made-up textbook chapters, written by hand for the retrieval tests.

- `ch1-heat-transfer.md`: Markdown; each paragraph is one long line (soft-wrapped). Definitions in
  bold, worked examples, figure captions, one fenced code block, a summary and exercises.
- `ch2-simple-statistics.txt`: plain text, hard-wrapped near 90 characters. Headings are either a
  title line underlined with `=` (level 1) or `-` (level 2), or a numbered line such as
  `2.3 Measures of spread` after a blank line (level = count of numbers).
