# nmlearn

Learning: quantized low-rank adapters beside frozen clusters, fitted forward-only from checked
outcomes, promoted only through a Step Check, loaded and unloaded as the rollback, never merged.
`unit`, `registry` (units live in `units/`), `isolation`, `outcomes`, `stepspec`, `forward`
(MeZO), `adapt`, `rls` (recursive least squares readout), `readout`, `route`, `ledger`,
`calibrate`, `tuner`, `learned`. `cartridge`: learned adapter cartridges (label, slot check,
per-request selection, disagreement rule). `preference`: the preference store under
`preferences/`, rule extraction, nearest-case recall.

Section checks: `neuromorph-nano check nmlearn` (writes to `tests/section-checks/`).
